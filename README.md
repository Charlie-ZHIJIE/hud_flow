# Simple Adder - HUD Environment

HUD evaluation environment for the Simple Adder problem (basic combinational logic).

## Problem

Implement a parameterized N-bit adder with carry output.

## Quick Start

```bash
docker build -t hud-simple-adder:latest .

export HUD_API_KEY="your-key"
export ANTHROPIC_API_KEY="your-key"

./run_eval.sh
```
