# Simple Counter - HUD Environment

HUD evaluation environment for the Simple Counter problem (basic sequential logic).

## Problem

Implement a parameterized N-bit counter with enable and reset.

## Quick Start

```bash
docker build -t hud-simple-counter:latest .

export HUD_API_KEY="your-key"
export ANTHROPIC_API_KEY="your-key"

./run_eval.sh
```
